# Calculator

A React calculator built with Vite.

## Prerequisites

- Node.js 20 or newer
- pnpm

## Install

```sh
git clone https://github.com/Hai5edfm/calculator-project.git
cd calculator-project
pnpm install
```

## Development

```sh
pnpm dev
```

## Tests

```sh
pnpm test
```

## Production build

```sh
pnpm build
pnpm preview
```
